## 1. 卡组理念

**核心思路：让敌人"打不出来"。**

- 攻击端：ATK 削减可叠加（苦修叠层、枷锁叠层、戒律堂光环、苦行僧反击），高攻大怪在 2-3 回合内被削成 0 攻摆设。
- 行动端：AP 透支（疲惫）与体力压制（禁足/霜沼/锁链卫兵）让敌人寸步难行，保护己方门。
- 质量端：忏悔永久压血、变羊直接消灭高价值单位、戒律裁决拆增益体系。
- 反制弱点：自身单位普遍低攻（2-3），依赖持续削弱而非爆发——**打不死就叠**，属于节奏/控制型卡组。

**费用曲线**：1费×1 / 2费×9 / 3费×6 / 4费×4 / 5费×1（总 21）。

## 4. 卡组联动（设计意图汇总）

1. **削弱引擎（枷锁流）**：枷锁术(2层) + 裁判官(攻击+1层) + 惩罚法典(每次攻击+1层) → 单回合可叠 3-5 层，每层 ATK-1 体力-1。配合苦修/缴械的即时降攻，4 回合内把 4 攻大怪削到 0 攻。
2. **行动封锁（禁足流）**：疲惫(AP-2) + 禁足(体力-3) + 霜沼(减速地形) + 锁链卫兵(攻击锁AP) → 敌人从"摸不到门"到"动不了"，形成铁桶防线。
3. **质量消灭**：苦行烙印/殉道者的变羊 + 忏悔的永久压血 + 凛冬祭坛的进入伤害 → 对高价值单体（重载章鱼、巨拳近卫）一击必废。
4. **增益封锁**：戒律裁决(单体) + 禁魔领域(区域) → 针对擢升之手的义肢体系（本作最强增益流）定向拆除。
5. **光环/亡语体系**：戒律殿堂(每回合全场降攻) + 忏悔者(死亡全场降攻) + 苦行僧(受击反削) → 敌人怎么打都在亏。
6. **经济引擎**：苦行信众(+1费/回合) + 冰晶祭坛(攻击时 +2费+抽1，2026-08-10 由回合开始改为攻击触发)——控制流最怕费用跟不上节奏，产费单位让"削弱"可以持续施压；双祭坛叠加 = 每回合 +4 费 +2 张。
7. **对己限制（双刃剑）**：禁魔领域敌我不分、霜沼会减速己方、忏悔/枷锁是永久资源——玩家需要规划"放哪/何时用"，控制卡组的决策深度。

## 5. 与现有体系的差异

- 现有势力：圣主教=治疗/信仰、擢升之手=增益成长（义肢）、门客=军事攻防。
- 禁欲修会 = **本作第一个纯"负增益"（Debuff 控制）势力**：buff 全部是减益、装备是负面装备、变身是变废柴、光环是削弱——机制取向与现有三势力相反，形成对抗性（对义肢流的天然克制）。

## 6. 框架限制报告（已跳过/降级实现）

| 需求 | 现状 | 处理 |
|---|---|---|
| "范围内驱散增益"（禁魔领域） | `RemoveBuffAction` 原只读 `ctx.TargetUnit`，而 EventBus filter 路径（有 TargetFilters 的被动）把目标放 `TargetUnits` 并把 `TargetUnit` 置 null（EventBus.cs:325） | **已实现（2026-08-10 框架修复）**：`RemoveBuffAction` 改为与 `ModifyStatAction` 同款兼容（TargetUnits 优先、TargetUnit 兜底）——环境被动 `[Shape(菱形,0)]` filter 路径下可多目标驱散 |
| "禁止治疗"（禁疗） | 无治疗修饰事件/动作（只有伤害修饰 ModifyDamageAction） | **跳过** |
| "禁止获得 Buff"（拦截） | EventBus 无拦截机制（事件均为事后触发） | 用"事后驱散"替代（禁魔领域） |
| 限制敌方费用/抽牌 | 敌方 AI 无费用与手牌体系 | **跳过** |
| "驱散全部增益"（无指定 ID） | `RemoveBuffAction.BuffID` 为空时不动作（必须指定 ID） | 戒律裁决/禁魔领域驱散 4 个已知增益（义肢/强壮/充能/指挥官） |
| 环境瓦片 | 环境图集仅 3 瓦（火焰之地/水/机械臂流水线） | 新环境复用 2:0 瓦片占位（`AtlasCoords`），美术素材就绪后加瓦片 |
